You have completed the **k3d (K3s in Docker)** scenario!

### Summary of Key Concepts:
- **k3d Architecture**: Running lightweight Kubernetes (k3s) clusters containerized inside Docker without overhead.
- **Cluster Management**: Utilizing the `k3d` CLI (`k3d cluster list`, `k3d node list`) for rapid lifecycle management.
- **Kubeconfig & Connectivity**: Automatically configuring `~/.kube/config` and interfacing with standard `kubectl` and `helm` tools.
- **Resource Management**: Creating and isolating environments using Kubernetes namespaces and deploying workloads.
